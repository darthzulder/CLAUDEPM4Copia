Alertas

HTML Example
          <lib-button-z type="primary" label="Alert Info" icon="info:line" [iconRight]="false" [disabled]="false" (eventClick)="mostrarAlertaInfo()"></lib-button-z>
          <lib-button-z type="primary" label="Alert Positive" icon="check:line" [iconRight]="false" [disabled]="false" (eventClick)="mostrarAlertaPositive()"></lib-button-z>
          <lib-button-z type="primary" label="Alert Alert" [iconRight]="false" [disabled]="false" (eventClick)="mostrarAlertaAlert()"></lib-button-z>
          <lib-button-z type="primary" label="Alert Negative" icon="close:line" [iconRight]="false" [disabled]="false" (eventClick)="mostrarAlertaNegative()"></lib-button-z>
Parámetros / Configuraciones de AlertZService
Propiedad Tipo Descripción
tipo Método Determina el tipo y color de la alerta.
Usar uno de los siguientes métodos:
alerts.info (informativa)
alerts.positive (éxito)
alerts.alert (advertencia)
alerts.negative (error)
message string Mensaje principal que se mostrará en la alerta.
title string Título opcional que aparece en la parte superior de la alerta.
widthPercent number Define el ancho de la alerta como porcentaje de la pantalla. Ejemplo: 100 para 100%.
autoCloseAfter number Tiempo en milisegundos antes de que la alerta se cierre automáticamente. Ejemplo: 5000 (5 segundos).
onShowAnimation string Animación al mostrar la alerta. Ejemplos: zoom-in, fade-in.
onCloseAnimation string Animación al cerrar la alerta. Ejemplos: slide-out, fade-out, shrink-out.
dismissible boolean Permite al usuario cerrar la alerta manualmente si es true.
Ejemplo de implementación
1. Importa el componente en tu HTML 
<lib-alert-z></lib-alert-z>
2. Inyecta el servicio en el constructor 
constructor(private alerts: AlertZService) { }
3. Llama la alerta desde tu componente 
// Ejemplo de alerta informativa
mostrarAlertaInfo() {
  this.alerts.info('¡Bienvenido a la app Zurich!', {
    title: 'Información',
    widthPercent: 100,
    autoCloseAfter: 5000,
    onShowAnimation: 'zoom-in',
    onCloseAnimation: 'slide-out',
    dismissible: true,
  });
}

Parámetros / Configuraciones de lib-tabs-z
Propiedad Tipo Descripción
headers Array<Object> Define las pestañas que se mostrarán.
Cada objeto debe tener:
  • title: Título visible
  • key: Referencia única para la pestaña (debe coincidir con el template o el key de data)
  • icon: (opcional) Icono a mostrar
Ejemplo: 
[{ title: 'Pestaña 1', key: 'con1', icon: 'home:line' }]
data Object Permite definir el contenido por key desde TypeScript.
Ejemplo TS: 
tabData = {
  con1: 'Contenido para la pestaña 1',
  con2: 'Contenido HTML para la pestaña 2',
  con3: 'Contenido para la pestaña 3',
};
Si existe un <ng-template #key>, tiene prioridad sobre data.
<ng-template #key> TemplateRef Permite definir un template HTML/Angular para el contenido de la pestaña.
El nombre del template (#key) debe coincidir con el key en headers.
Tips: Puedes mezclar data y <ng-template #key> en un mismo componente. Si ambos existen para la misma pestaña, el template tiene prioridad.
